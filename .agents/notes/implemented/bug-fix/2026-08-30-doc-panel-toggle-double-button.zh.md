# Agent Note: 文档面板开关在列过渡期间不得重复绘制

Status: implemented

[English](2026-08-30-doc-panel-toggle-double-button.md) | 中文

## 问题

收起文档面板时，两个开关按钮会在同一坐标处同时绘制。`DocPanelRoot` 用 `hidden={!collapsed}` 显示其 portal 化的重开按钮——状态一变它就立即翻转——而框架的网格轨道要经过 `--ds-transition-duration-slow`（300 ms）才动画到零。整个过渡期间，面板内的折叠按钮仍在绘制（被收窄的列裁剪），于是两个按钮占据同一个右上角盒子——一个双重字形。对真实收起动画的 DOM 埋点显示：点击后 7 ms 起两个元素同时可见；动画中后段，折叠按钮的布局盒最多右漂 20 px，从其右缘漏出一条细边。

收起终态还有第二个现象：列宽为零时，会话列延伸到框架右缘，其右对齐的会话头部工具（"Session 日志"导出药丸）正好落在 portal 化的重开按钮之上——桌面壳中位于其下方 12 px——看起来像第二个叠放的按钮。

修复期间 web e2e 的可访问性 golden 暴露了第三个：常驻挂载的列主体收起时只带 `inert`，而 Chromium 会把 inert 子树保留在可访问性树里（以 disabled 暴露），于是收起面板的内容仍可被辅助技术读到。

前两个修好后，桌面模式又暴露出第四个：收起动画的最后阶段，面板内折叠按钮一边被裁剪一边向窗口边缘滑出最多 20 px，看起来像被遮挡、静止后又"恢复"。`.header` 带 10 px 侧内边距；列宽小于该内边距时，其内容盒——绝对定位的折叠按钮经由 `.titlebar` 得到的定位上下文——会被推到框架右缘之外，按钮随之漂移。

## 决策

- **一个 portal 化到框架 overlay 层的角落开关始终可见。** `DocPanelRoot` 在两种状态下都渲染同一个位于框架右上角的按钮；其标签和动作随列状态翻转（收起为 `panel.expand`/`openPanel`，展开为 `panel.collapse`/`closePanel`）。该节点永不卸载、永不移位，因此收起就是静止按钮之下的一次纯轨道动画——两个节点之间不存在交接，自然也就不存在需要针对过渡设闸的东西。
- **文档面板收起时，会话头部让出框架右上角。** AppFrame 把 `docCollapsed` 作为 owner prop 传给 `conversation` 槽位；ConversationRoot 将其转发给 `conversation.session.header` 槽位；头部给 `.headerUtilities` 加 20 px 右外边距（合计距框架边缘 48 px——相对 right:12 px 加 28 px 宽的按钮区留 8 px 间隙）。
- **收起主体在 inert 之外再加 aria-hidden。** 单独的 `inert` 只把它移出焦点和交互，移不出可访问性树；两个属性齐备后，收起主体对辅助技术不可见，而其绘制——以及裁剪它的轨道动画——照常进行。

## 后果

- 收起动画的每一帧都在同一坐标处恰好绘制一个开关：没有双重字形、没有两节点之间的空角、没有向窗口边缘的漂移。
- 收起面板的内容不再到达辅助技术；展开时同一次渲染移除两个属性。
- 收起终态中，"Session 日志"药丸（以及未来任何右对齐的头部工具）在两种壳里都避开开关。
- 两种状态下角落都由开关占据，因此展开面板的标题栏条带不再自带任何控件（它仍是桌面壳的拖拽区）。

## 相关决策

这些开关上的 tooltip 气泡闪烁已单独修复（2026-08-30-tooltip-click-flash），方式是 hover 由指针移动启动。该修复消除了那条 note 中记录的对"延迟取消隐藏重开按钮"的唯一反对理由（"按钮仍会出现在静止光标之下——同样的合成 mouseenter、同样的延迟气泡"）：在"移动才启动"规则下，无论按钮何时出现，没有真实指针移动就不会弹出气泡。

## 备选方案

- **两个常驻按钮加落定门控的交接。** 面板内折叠按钮钉在角落（锚到 `.panel`、由轨道裁剪），ResizeObserver 观察 section 盒，列宽小于按钮右缩进时在同一次渲染中隐藏折叠按钮并取消隐藏 portal 按钮。本会话中途曾实现，随后被替换：两个节点之间仍留有一帧空角、读起来像闪一下，而且保留了 ResizeObserver 机制和一个与 CSS 内边距耦合的宽度常量。一个标签翻转的单一节点把两者都删掉了。
- **匹配 `--ds-transition-duration-slow` 的超时。** 把 TypeScript 耦合到 CSS token 数值上；token 变更时会漂移，且需要为 reduced motion 加特例。
- **纯 CSS 给工具留位（center 列加 padding，或从特性 CSS 选择 `data-doc-collapsed`）。** 碰撞只在文档面板收起时存在，无条件缩进会在展开态白白浪费 48 px 头部宽度；从另一个包的样式表向上够框架的 data 属性会形成隐式跨包契约，owner prop 通道正是用来替代它的。
